Nothing is computed in Liquid — a number rendered here that the API would not return is the one thing this must never do. Renders only where the generator wrote an entry, which is only the `brief` tier and above. Below that the block is simply absent: a distribution over four providers is not a small brief, it is a wrong one, and MIN_COHORT exists to stop it being published. WHAT THIS BLOCK DELIBERATELY DOES NOT SAY It never calls a cohort a "market". 1,171 of the 1,243 briefs are tags, and the tag vocabulary mixes real markets (`payments`, `open-banking`) with API resource nouns lifted out of OpenAPI operations (`activities`, `addresses`, `webhooks`). "The FinOps market scores 45.8" is a claim; "the 30 providers in the catalog tagged FinOps score 45.8" is a measurement, and it is true for every kind on the ladder. So the population sentence states the roster and nothing more. CSS is `cb-`-prefixed and self-contained.
