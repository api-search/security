{% comment %} Collapsible provider list grouped by rating band. Used by every listing that shows providers — use cases, features, VC portfolios, secondary market, and the providers/APIs indexes. The ordering contract is set in scripts/lib_rating.py: bands descending (exemplar → minimal, unrated last), composite descending inside a band, then A–Z. Exemplar and Strong render OPEN; everything below renders CLOSED, because on a list of thousands the long tail is noise until it's asked for. That choice lives in lib_rating.BANDS_OPEN_BY_DEFAULT and arrives here as `group.open`. Two ways to hand it the rows. Most callers pass `group.items` as full row hashes and that is it. The tag pages can't: there are ~275,000 (tag, provider) pairs, so a full row per pair is ~200 MB of data. They pass slug STRINGS in `group.items` plus a shared `rows` lookup table, and the join happens here. Params: bands - array of {band,label,blurb,open,count,items} from group_by_band() rows - OPTIONAL slug -> row map.
