Distil, never invent. Only OpenAPI a provider published itself is counted, never a contract APIs.io generated, and a company counts once however many files it publishes. A property is core when at least half the providers with a readable schema declare it. A provider's coverage is a mapping, not a grade, and does not enter any score.
